## 流程

1. Dev Agent 在表中追加一行（状态 = 待验证）
2. 通知 QA Agent 取任务
3. QA 验证后更新状态（已通过 / 已退回），并同步 `demands/REQ-xxx/status.md`
4. 已完成的行归档到下方「已处理」
